# CNAUS Adoption Scope (Non-Core)

CNAUS is a released, versioned standard for deterministic verification of registry and proof artifacts.

This Adoption Pack is not normative. It exists to reduce adoption friction by providing:
- review instructions,
- minimal implementation paths,
- report templates for third-party review and conformance claims.

The normative reference is always an immutable CNAUS release tag `vX.Y.Z` in the canonical standard repository.
