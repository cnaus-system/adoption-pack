# HOW TO REVIEW (Adoption Pack)

## 1. Purpose
This document explains how to review the CNAUS Adoption Pack and provide actionable feedback.

## 2. What to review
Review the Adoption Pack materials in this repository:
- `README.md`
- `SCOPE.md`
- `HOW_TO_IMPLEMENT.md`
- `templates/`

This Adoption Pack is **Non-Core** and **Informative**. Normative specifications live in the CNAUS Core Standard repository.

## 3. Normative reference (CNAUS Core Standard)
Use the latest tagged release in the Core Standard repo (`registry-core`) as normative reference.

## 4. How to submit feedback
Preferred:
- Open a GitHub Issue in this repository (Adoption Pack), or
- Submit a Pull Request with suggested edits.

Alternative (written only):
- Submit a review memo using `templates/REVIEW_MEMO_TEMPLATE.md`.

## 5. What “good feedback” looks like
Please include:
- The file/section reference
- The exact problem (ambiguity, missing assumption, contradiction)
- A proposed fix (text suggestion) where possible

## 6. Review checklist (minimum)
- Is the scope unambiguous?
- Is there a clear “first successful implementation path”?
- Are required inputs/outputs clearly stated?
- Are the templates sufficient to create a review memo / conformance report?
- Any wording that could be misinterpreted as normative when it is not?
- Any missing links to Core Standard artifacts (release/tag, validate instructions)?
