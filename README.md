# CNAUS Adoption Pack (Informative)

This repository provides non-normative materials to support review, adoption, and implementation of the CNAUS Standard.

Normative CNAUS releases are published in the canonical standard repository:
- CNAUS Standard: `cnaus-system/registry-core` (use immutable tags `vX.Y.Z`)

Entry points:
- What CNAUS is (scope): `SCOPE.md`
- How to review: `HOW_TO_REVIEW.md`
- How to implement: `HOW_TO_IMPLEMENT.md`
- Templates (review memo, conformance report): `templates/`
